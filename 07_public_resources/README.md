# Public genomic-resource integration

The manuscript reports descriptive gene-level comparison with the GWAS Catalog, CTD Gene-Disease Associations, Open Targets and DisGeNET. It does not provide the exact downloaded tables or API queries needed for exact historical reproduction.

Therefore this folder should contain:

- the dated input/export files actually used;
- the query date;
- the exact query terms/filters;
- the resulting gene lists;
- a simple overlap script.

Do not silently replace the historical datasets with current versions and call the result an exact reproduction.
