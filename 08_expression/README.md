# GTEx/HPA expression analysis

The reviewer-revision manuscript adds GTEx bulk-tissue and Human Protein Atlas (HPA) tissue/cell-type expression analyses for CACNA1G, BSN, HCFC1 and LARGE2.

The exact GTEx release, HPA release/API export, filters, cell annotations and plotting code are not fully documented in the manuscript text available here. Therefore this folder contains the analysis specification but not invented API calls or values.
